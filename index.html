نبذة عني

أنا عبدالرحمن الصالح، مطوّر مواقع وتطبيقات ويب بخلفية في علوم الحاسب.

أعمل على مواقع الشركات والمتاجر الإلكترونية باستخدام WordPress وNext.js.

أهتم بتبسيط خطوات المستخدم وتحويل احتياجات فرق العمل إلى واجهات واضحة.

المهارات

  • HTML وCSS

    بناء صفحات متجاوبة وتنظيم المحتوى وتنسيقه.

  • JavaScript

    إضافة تفاعلات واضحة للواجهات داخل المتصفح.

  • React وNext.js

    بناء واجهات تطبيقات الويب وتنظيم مكوناتها.

  • WordPress وWooCommerce

    تطوير مواقع الشركات والمتاجر وإدارة محتواها.

  • تحليل المتطلبات وتصميم الواجهات

    فهم احتياجات المستخدم وتحويلها إلى شاشات ومسارات عمل.
